# BrainBoy Time Machine

Рандомайзер для розыгрыша подарков на игре BrainBoy (интеллектуальная битва).

## Запуск
- **GitHub Pages:** Settings → Pages → Deploy from branch → `main` / root. Приложение откроется по адресу `https://<user>.github.io/<repo>/`.
- **Локально:** любой статический сервер в папке проекта (`npx serve .` или `python -m http.server`), затем `http://localhost:8000/`.

## Возможности
- Честный выбор номера: `crypto.getRandomValues()` без смещения по модулю, режим без повторов, история и CSV.
- Калибровка, настраиваемое время розыгрыша, 6 способов показа номера.
- Скины: фирменный BrainBoy, 5 цветовых тем, 4 времени года, 9 праздников; панели управления меняются вместе со скином.
- Кольцо с названиями команд (список редактируется в настройках → «Команды»).
- Языки: казахский, русский или оба сразу; текущая дата сверху.
- Окно зрителей, синхронизированное с ведущим.

## Офлайн-версия
`BrainBoy Time Machine (офлайн).html` — один файл со всем внутри (шрифты, картинки, скрипты). Можно скопировать на флешку и открыть двойным кликом без интернета.

## Файлы
- `index.html` — переход на приложение
- `BrainBoy Time Machine.dc.html` — приложение
- `tm-engine.js` — отрисовка машины, анимации, звук
- `support.js` — среда выполнения страницы
- `assets/` — логотип и маскот
- `_ds/` — стили

Настройки, команды, история и сеансы хранятся в localStorage браузера.


## Обновления
В корне лежит `version.json` с номером сборки. При каждом обновлении в репозиторий загружайте его вместе с остальными файлами — по нему онлайн- и офлайн-версии узнают, что вышла новая версия. Офлайн-файл скачивает себя заново с сайта: Настройки машины → Интерфейс → Обновления.
